# Книжный план — лабораторная №8

Морозова Анастасия Алексеевна, группа 221341, вариант 3, лабораторная №8.
Методические указания, часть 1, страницы 15–16.

## Как посмотреть результат

В PowerShell из папки проекта с Python 3.10 или новее:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[test]'
.\.venv\Scripts\python.exe -m reading_plan
.\.venv\Scripts\python.exe -m pytest -q
```

Без аргументов программа читает два временных примера, выводит прогресс
по каждой книге и сумму оставшихся страниц. Можно передать свои файлы:

```console
python -m reading_plan novels.csv weekend.csv
```

Пример содержимого файла в UTF-8:

```csv
title,total,read
Маленький принц,96,42
Два капитана,640,180
```

## Упражнения варианта 3

- **Среднее №3.** Функция `remaining_pages` и параметризованный тест `pytest`.
- **Среднее №5.** Исходники пакета в `src/reading_plan`, сборка через `pyproject.toml`.
- **Среднее №9.** Свойство `BookProgress.pages_read` проверяет диапазон при изменении.
- **Повышенное №3.** `ReadingRepository` описывает получение книг, а
  `CsvReadingRepository` хранит детали чтения CSV. Функция загрузки принимает
  репозитории через этот интерфейс.
- **Повышенное №7.** `asyncio.to_thread` переносит чтение каждого файла в рабочий
  поток, а `asyncio.gather` запускает операции совместно и сохраняет порядок списков.
